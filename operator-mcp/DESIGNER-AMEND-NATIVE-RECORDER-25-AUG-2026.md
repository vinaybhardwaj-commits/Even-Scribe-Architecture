# Designer amend — the room process is a recorder, not a wrapped page
25 August 2026. Scribe Designer. Amends `DESIGNER-REPLY-KIOSK-APP-AND-25-AUG-STATE-25-AUG-2026.md` §1 only.

V asked if I had understood. I had not. I treated "rewrite" as a threat to the tape. He meant the **app**: the process that holds the microphone in the room.

## Corrected lock

The room kiosk stops being a browser. It becomes an **independently installed recorder** on the Mac.

- It is not a Safari/Chrome tab.
- It is not the current page inside Electron, Tauri, or WKWebView. That is still a browser, and every failure in the 24 August note is a browser failure.
- It launches at login, restarts itself, returns after power, cannot be closed by a passer-by, holds the machine awake while recording, and keeps reporting when it is not.
- The operator can restart **that process** remotely.

## What is not rewritten

The tape **contract**. Five-minute pieces, the same content-type, the same upload, retry, verify, R2 keys, command bus, and brain. The archive, the API, and the operator page stay. If a native capture path cannot emit a piece the server already accepts, the path is wrong, not the server.

I will push back if the rewrite reopens rotation, stitching, or a new audio format. I will not push back on leaving Chromium.

## What this does to the rest of this morning's reply

§2 (lamp + Start / Pause / Mark), §3 (day opens with the tape; remote mark is fallback), and §4 (alarm rule, spare-exists is a device, hear 24 August with Whisper) stand. Only §1 changes: wrapper is no longer the first move. The first move is a native recorder that speaks today's tape.
