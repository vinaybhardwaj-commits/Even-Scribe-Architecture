## 1. Problem
Tonality Rubric V0 scores patient voice on room tape (C270/TONOR, 16 kHz, far-field, en/kn/hi code-mix) with two **categorical** SER heads: `Aniemore/wavlm-emotion-v1-crosslingual` (int8) and `emotion2vec/emotion2vec_plus_large`. On our tape:
- **Coverage:** only 45/96 pitch clips have a scorable patient voice, and 48/96 a validated patient speaker.
- **WavLM** reads *neutral* in 101/116 patient windows. It is a mostly-Russian 7-class head (spontaneous macro-F1 0.36 per its model card).
- **emotion2vec+** is overconfident (median top score 0.944) and never puts angry or fearful on top. Its cool readings vs text distress give κ −0.04. Its only weak signal is late-warm vs reassurance (κ 0.44, n=37).
- Voice tension does not predict acceptance (6/14 vs 6/18).
- No clinician affect gold exists.

## 2. Goals / non-goals
**Goals**
1. Fix patient attribution and coverage first (Step 0).
2. Measure **dimensional** patient affect (arousal, valence, dominance) plus interpretable prosody, as **within-speaker deltas** and **relative to the doctor**.
3. Fuse with the TypeSafe Jev text judgments. **Text decides; voice is evidence.** Emit a text–voice disagreement flag.
4. Prove value against **decisions and doubts** (accept/defer, unresolved doubts), beyond what the text gives.
5. Widen the ETA schema so any model can write results (no more WavLM-only columns).

**Non-goals**
- Ranking doctors on voice affect.
- Empathy scores from F0 synchrony.
- Letting an audio-LLM write scores.
- Building anything before Vinay's GO.

## 5. Data contracts
### 5.1 Patient span (T-1 output, JSONL)
```json
{"window_id":"str","speaker_idx":1,"start_ms":142860,"end_ms":155570,
 "p_speaker":0.93,"p_overlap":0.04,"snr_db":18.2,"voiced_s":9.8,
 "role":"patient","role_conf":0.88,"role_method":"ecapa+sarvam+content",
 "reason":null}
```
`reason` ∈ {`no_patient`, `overlap`, `low_snr`, `too_short`, `attender_speaks_for_patient`}. When it is set, the span is not scored.

### 5.2 Per-turn features (T-4/T-5/T-6, parquet)
`window_id, speaker_idx, start_ms, end_ms, egemaps_*[88], compare_ref, f0_med, f0_iqr, loud_med, rate_syl_s, pause_ratio, resp_latency_ms, talk_share, A_audeering, V_audeering, D_audeering, A_vox, V_vox, D_vox, A_ody, V_ody, D_ody, e2v_ref, whisper_ref, *_delta_self, *_rel_doctor, model_versions{}`

### 5.3 Gold labels (T-3, CSV from the Designer kit)
`item_id, window_id, clip_id, is_repeat, arousal(1-5), valence(1-5), engaged, anxious, resistant, words_tone_mismatch, not_patient, unusable (0/1), confidence(low|medium|high), notes, labelled_at_ist, seconds_spent, plays, context_plays, rater, room, date, doctor_uid8, phase, outcome, lang, start_s, end_s, patient_speech_s, kit_version, seed`

- The windows are 180, from 45 consults with validated patient speakers (Oct + Sep pitch packs, 13 doctors, 8 rooms), plus 18 hidden repeats.
- `window_id = <clip_id>_p<start_ms 7-digit>`.
- Times are relative to the clip WAV.

### 5.4 Schema widening (T-9, replaces WavLM-only mig 0089 for new writes)
```sql
create table room_affect_run (
  id bigserial primary key, window_id text not null, diarize_run_id bigint,
  model_id text not null, model_version text not null,
  kind text not null check (kind in ('categorical','dimensional','features','embedding_ref','fused')),
  calibration_version text, state text not null, started_at timestamptz, finished_at timestamptz,
  unique (window_id, model_id, model_version, kind));
create table room_span_affect (
  id bigserial primary key, run_id bigint references room_affect_run(id),
  window_id text not null, speaker_idx int not null, start_ms int not null, end_ms int not null,
  source_refs jsonb, clip_r2_key text,
  values jsonb not null default '{}', arousal real, valence real, dominance real,
  confidence real, top_label text, coverage_reason text);
-- per-kind CHECKs: dimensional rows need arousal and valence; unscorable rows need coverage_reason.
-- 0089 tables (room_emotion_window / room_span_emotion) stay as read-only history.
```
Same principle as 0089: no identities, and roles only via `room_turn_speaker`.

### 5.5 MCP read surface (T-10)
`scribe_voice_affect(window_id | encounter_id)` returns, per patient turn and window: `arousal_delta, valence_delta, hesitation, settled_at_close, confidence, coverage_reason, text_voice_disagreement, jev_verdicts{}`. It returns `unscorable` with a reason and never reports "neutral" for missing voice.

## 6. Evaluation bar (pre-registered, T-8)
- **Gold agreement:** CCC for arousal and valence (primary); macro-F1 and AUROC for flags; ECE after calibration. Within-speaker and pooled. Vinay's intra-rater repeat agreement (weighted κ / ICC) is the ceiling.
- **Outcome-linked:** ΔAUROC or a likelihood-ratio test, with bootstrap CI, for Jev text + voice vs Jev text alone, on **accept/defer**, **unresolved doubts** and Vinay-judged distress/confusion.
- **Ship to production only if** both hold:
  - (a) the new signal beats e2v late-warm κ 0.44 on the reassurance proxy, and
  - (b) there is a non-zero beyond-text gain on ≥ 1 outcome.
  
  Otherwise voice stays a listen-list pointer.
- **Coverage KPI:** validated patient speaker ≥ 80% on a hand-checked 50-clip set. Coverage is reported next to every metric.
- **Slices:** C270/TONOR, en/kn/hi, SNR terciles, doctor, sex, overlap density.

## 9. Risks
- **Coverage bias:** quiet or attender-mediated patients are under-scored, so never read "unscorable" as calm.
- **Single-rater gold:** mitigated by blinding, hidden repeats and the optional second check.
- **Cross-lingual valence drift:** use deltas, not raw trends.
- **Room/mic confound:** use doctor-relative and per-room baselines.
- **Audio-LLM lexical bias:** explainers only.
- **Licence quotes:** fall back to permissive backbones plus parselmouth.
